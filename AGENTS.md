# module_bmp280 — датчик температуры и давления BMP280

> **Опциональный модуль.** Подключается через `src_filter` (define-флаг `MODULE_BMP280`
> выводится из `src_filter` автоматически через `[registry]`).

Датчик BMP280 (I2C): температура и атмосферное давление. Публикует на ресурсную шину
`core_state` только доступность и значения; веб-страница и терминал — только просмотр.

- **Репозиторий:** https://github.com/Arcanum753/bmp280
- **Папка:** `src/module_bmp280/`
- **Флаг активации:** `MODULE_BMP280` (генерируется в `src/modules_defines.h` из `src_filter`)
- **Registry:** `object=module_bmp280`, `define=MODULE_BMP280`, `namespace=bmp280`,
  `web=1`, `loop=0`, `res=1`
- **Платформы:** ESP8266/ESP32 (тестирование — ESP32)
- **Зависит от ядра:** `core_web`, `core_state`, `core_task`, `core_terminal`, `core_json`

## Назначение

Чтение BMP280 по I2C (`Wire`), автоопределение адреса `0x76`/`0x77`, чип идентифицируется
по `CHIP_ID` (`0xD0` == `0x58`). BME280 (`0x60`) не поддерживается.

## Функциональные требования

- FR-BMP280-1: Автоопределение адреса `0x76`/`0x77`; проверка `CHIP_ID == 0x58`.
- FR-BMP280-2: Чтение калибровки `0x88..0xA1` и компенсация по формулам Bosch.
- FR-BMP280-3: Публикация `bmp280.available` (BOOL), `bmp280.temperature` (F32, °C),
  `bmp280.pressure` (F32, hPa).
- FR-BMP280-4: Периодический опрос через `core_task.every("bmp280_poll", …, 1000)`.
- FR-BMP280-5: Веб-страница `bmp280.html` — только показ значений, обновление раз в 1 с.
- FR-BMP280-6: Терминальная команда `bmp` — статус и значения.

## Аппаратные интерфейсы

| Интерфейс | Выводы по умолчанию | Примечание |
|-----------|---------------------|------------|
| I2C (BMP280) | ESP32 21/22, ESP8266 4/5 (SDA/SCL) | общая шина `Wire`; адрес `0x76`/`0x77` |

## Веб-интерфейс

| Метод | URL | Назначение |
|---|---|---|
| GET | `/bmp280/info` | CVT: состояние, адрес, chip id, показания |
| GET | `/bmp280/read` | CVT: только показания (опрос раз в 1 с) |
| GET | `/bmp280/ver` | версия модуля |

Страница `bmp280.html` (пункт меню — `web/_menu.html`). Полей редактирования нет.

## Ресурсы шины (namespace `bmp280`)

| Ресурс | Тип | Описание |
|---|---|---|
| `bmp280.available` | BOOL ro | датчик найден, калибровка валидна |
| `bmp280.temperature` | F32 ro | температура, °C |
| `bmp280.pressure` | F32 ro | давление, hPa |

`<ns>.save` и `<ns>.mode` не регистрируются: у модуля нет сохраняемых настроек.

При потере датчика публикуется `available=false` и значения `0`; поиск повторяется на
каждом тике опроса (hot-plug).

## Терминал

Компонент `module_bmp280`, команда `bmp`, `editable = false`.

| Команда | Назначение |
|---|---|
| `bmp` / `bmp show` | состояние, адрес, chip id, температура, давление |
| `bmp help` | справка |

## Ограничения

- BME280 (`CHIP_ID 0x60`) не поддерживается.
- Клоны BMP280 могут иметь нестандартную калибровку; при абсурдных значениях смотреть лог
  `DEBUG_BMP280`.
- Настройки датчика (oversampling/filter) фиксированы: `ctrl_meas = 0x57`,
  `config = 0x08`.
- Модуль не сохраняет ничего на FS: конфига нет.

## Критерии приёмки

- `esp32-i2c-mapper` (или иной env с модулем) собирается.
- Страница `bmp280.html` открывается, показания обновляются.
- `/state/catalog` содержит `bmp280.available|temperature|pressure` с `rw=false`.
- Команда `bmp` печатает значения; при отключённом датчике — `not available`.
